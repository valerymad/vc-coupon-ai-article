# Статья про Coupon AI для VC

## Что где

- `article_v2_vc.md` — текст статьи. Источник истины: все правки текста только здесь.
- `out/` — готовые картинки и видео, в том виде, в каком они загружаются на VC.
- `visuals/`, `cover/`, `demo/` — исходники иллюстраций (HyperFrames): схемы 02–05, обложка, демо-ролик.
- `preview/build_pdf.py` — собирает PDF-превью статьи в духе VC.

## Разметка в MD под блоки VC

- `![текст](out/файл.png)` — картинка, текст в квадратных скобках идёт подписью под ней.
- Строка с `>` — блок «Цитата». Строка `[Блок-цитата ... подпись: ...]` под ней задаёт подпись цитаты.
- `[Видео: ...] — подпись: ...` — видео из `out/`.
- Абзац целиком жирным — подзаголовок внутри раздела.

## Как работать

1. Создать ветку, внести правки в `article_v2_vc.md`, открыть pull request.
2. Обсуждение и замечания — комментариями к строкам в PR.
3. PNG в `out/` руками не править. Правку картинки описать комментарием, её перерисуют из исходников.

Превью статьи с картинками видно прямо на GitHub, если открыть `article_v2_vc.md`. PDF-превью (нужны macOS и Google Chrome):

```bash
python3 preview/build_pdf.py
```
